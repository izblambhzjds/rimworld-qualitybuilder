## Overview

QualityBuilder adds a target quality setting to RimWorld construction jobs, causing colonists to deconstruct and retry any furniture or item that does not meet the configured minimum quality level. This automates the tedious process of manually demolishing substandard crafted items and restarting build orders to achieve Excellent or Masterwork furniture throughout a colony.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **RimWorld QualityBuilder** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Target Quality Setting** | Set minimum acceptable quality level per construction job type |
| **Auto Deconstruct Retry** | Substandard items are automatically deconstructed and rebuilt |
| **Per-Item Config** | Different target quality levels for beds, art, workbenches, and furniture |
| **Materials Recovery** | Deconstructed items return partial materials for the retry build |
